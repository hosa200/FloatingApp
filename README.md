# Nusuk AI Floating Helper (تطبيق نسك العائم)

تطبيق أندرويد عائم (Floating Bubble) يتحكم تلقائياً في مسابقة وتحدي نسك على الهاتف مباشرة دون الحاجة للكمبيوتر أو كابل أو تفعيل خيارات المطورين.

---

## الميزات الرئيسية:
1. **نافذة عائمة (Floating Widget):** تظهر فوق تطبيق نسك مع أزرار تشغيل/إيقاف، وحالة السؤال، وزر شحن المفاتيح (+10).
2. **بنك أسئلة مدمج (550+ سؤال):** يحتوي التطبيق محلياً في `assets/qa_bank.json` على جميع الأسئلة المحلولة والمتحقق منها بنسبة 100%.
3. **تكامل مع Google AI Studio:** في حال ظهور أي سؤال جديد غير مسجل، يقوم التطبيق فوراً باستدعاء Gemini 1.5 Flash عبر الـ API Key الخاص بك من Google AI Studio لحل السؤال بدقة تامة.
4. **شحن المفاتيح برمجياً:** يتصل مباشرة بالـ Worker لجلب الأكواد وتفعيلها.
5. **خدمة إمكانية الوصول (AccessibilityService):** لقراءة نصوص الأسئلة والخيارات والضغط الآلي على الإجابة الصحيحة وتأكيدها.

---

## كيفية بناء ملف الـ APK بدون تثبيت Android Studio (3 طرق مجانية):

### الطريقة الأولى (الأسهل والأسرع - عبر GitHub Actions):
1. ارفع هذا المجلد إلى مستودع جديد على حسابك في GitHub (New Repository).
2. بمجرد رفع الملفات، ستعمل الـ **Actions** تلقائياً بفضل ملف `.github/workflows/build-apk.yml`.
3. ادخل على تبويب **Actions** في المستودع بعد دقيقتين، وقم بتحميل ملف **`Nusuk-AI-Helper-APK`** مباشرة وثبته على هاتفك!

### الطريقة الثانية (عبر Google Project IDX - بيئة جوجل السحابية):
1. ادخل على [Google Project IDX](https://idx.google.com/).
2. اختر **Import Repo** وضع رابط مستودع GitHub الخاص بك، أو أنشئ مساحة عمل فارغة وارفع المجلد إليها.
3. سيفتح لك بيئة تطوير كاملة داخل المتصفح، افتح الـ Terminal واكتب:
   ```bash
   ./gradlew assembleDebug
   ```
4. سينتج ملف الـ APK في مسار:
   `app/build/outputs/apk/debug/app-debug.apk`

---

## خطوات التشغيل على الهاتف (Vivo V2231):
1. بعد تثبيت الـ APK على الهاتف، افتح تطبيق **Nusuk AI Helper**.
2. اضغط على **تفعيل نافذة العرض فوق التطبيقات (Overlay)** وفعّل الخيار للتطبيق.
3. اضغط على **تفعيل إمكانية الوصول (Accessibility Service)** وفعّل خدمة `Nusuk AI Helper`.
4. (اختياري) ضع مفتاح الـ Gemini API من [Google AI Studio](https://aistudio.google.com/) في الخانة واضغط حفظ.
5. اضغط **تشغيل النافذة العائمة والبدء**.
6. افتح تطبيق نسك وادخل التحدي، واضغط **تشغيل** من النافذة العائمة ليقوم بالحل والشحن تلقائياً!
